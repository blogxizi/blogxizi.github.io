大爷叫什么名字我忘啦，大爷60岁

第一次见他是看到他从垃圾桶里捡别人喝过的饮料和吃过的外卖

我当时看到觉得很心酸，他做这些事情的时候总是会反复确认旁边没有人才敢

我就去给大爷送了50元人民币，这是我们第一次遇见

我对大爷说我给你50元但你必须要回答对三个问题，然后这50元可以随便花

好的问题开始！

- [x] “面包是什么做成的”

​       “不是麦子吗”大爷文思泉涌飞速地回答

- [x] “1+1等于几”

​       “不等于2吗”大爷这次有点疑惑

其实我问这个问题主要是想检测一下大爷智利有没有问题从他的疑惑我就知道没问题啦

- [x] ”一斤等于多少两“

​    这个问题他没回答上来

- [x] “今年是多少年”

​        “2025年”

恭喜大爷成功回答三个问题，现在您可以随意支配这50元

最后大爷买了11块钱的大瓶可乐加一个小瓶我又给他补了一块钱

手上握着40块钱死活不愿意花了，然后告诉我这四十块他可不可以留着

我说不能后来我心软了，就丢给他我就走了



后来又看到他了

我说你晚上在哪里睡觉，他说路边

我问为什么不在地下室比如过=街通道

他说警察会抓他，不给在那里睡觉

我说你咋不去救助站，他说不知道

他估计不知道还有这么个东西，其实我也不知道是不是有这么个地方

他说他不想被警察抓去，抓去就会被送回他的老家，在那里他什么都没有

我说那你的亲人呢，他说爸爸妈妈很早就死了，只有一个哥哥

他是残疾人，他的土地被他哥哥霸占，他的残疾补助金一年好像是一百多元的巨款也被他哥哥侵占

他说之前警察给他送回他的老家遇见他的哥哥，他的哥哥会打他虐待他

而且在那里他真的搞不到吃的老家是淮南的，在合肥他可以从垃圾桶里捡一些吃的

后来我不知道他通过什么途径又回到了合肥

他总是装作自己是一个正常人，其实确实是

他只是害怕警察再把他抓回他的家乡



你为什么不去要饭呀

他说他是一个有坚持的人

我们的国家很强大了，他偶尔看到新闻也会看到我们社会的发展

在这样一个伟大的国家要饭是一件很丢脸的事情丢我们国家的脸

我听着很心痛，哀其不幸，怒其不争！

因为我始终认为人生而自由平等，生存的权力不应该被这样压抑

我询问了他的收入因为眼睛有残疾加上拾荒竞争压力不小

他每个月的收入高达几十块人民币巨款，生意差的时候

生意好的时候他每个月可以赚100多块钱



我走了

合肥市长江路最中心的地带，老公交车站那里

夜晚长江路市委党校的建筑十分巍峨

一位老者在门口不远处的椅子上度过了一夜又一夜

你们说他还在吗？或许会有他的继任者吗？

又会是谁冷

那天晚上，没有风

但是那天的合肥很冷！
