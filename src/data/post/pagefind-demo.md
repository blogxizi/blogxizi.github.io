# Blogxizi 搜索功能测试

这是一篇临时创建的示范文章。

## 测试全文搜索

Blogxizi 使用 Astro 构建静态博客，并通过 Pagefind 提供全文搜索功能。

你可以尝试搜索以下关键词：

- Astro
- Pagefind
- Linux
- Ubuntu
- RTX 4080 SUPER
- 全文搜索

如果这些关键词能够被搜索到，就说明文章索引工作正常。

这篇文章仅用于部署前测试，之后可以删除。
